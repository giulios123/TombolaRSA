# Product context

L'app viene usata come attivita ricreativa in una RSA, senza denaro o gioco d'azzardo. L'operatore deve poter gestire l'estrazione con pochissimi controlli, su notebook o tablet e con numeri leggibili a distanza.

Durante la partita la configurazione programmata deve rimanere discreta nell'uso normale. Non e richiesta protezione contro un utente tecnico con developer tools. Non devono essere raccolti nomi, dati sanitari, cronologie server o altri dati personali.
