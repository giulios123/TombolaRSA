# Project brief

Tombola RSA e una web app statica, locale e senza dati personali. Nel setup l'operatore sceglie una delle 90 cartelle ufficiali e l'estrazione K. Il sistema prepara una permutazione di 1-90 nella quale quella cartella e l'unico vincitore possibile esattamente a K. La vista di gioco non mostra queste informazioni e funziona come un normale tabellone elettronico.

Priorita V1: dataset corretto, solver dimostrabilmente corretto, estrazione affidabile, leggibilita e semplicita.
